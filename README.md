# 康源智慧人资平台 (Smart HR Platform)

集团化人力资源管理系统，涵盖考勤、薪酬、员工、规则引擎等模块，支持规则自定义与工资自动核算。

## 功能模块

| 模块 | 说明 |
|------|------|
| 数据看板 | 集团人资运营数据总览（员工数、出勤率、人工成本、薪酬状态等） |
| 考勤管理 | 考勤记录查询、异常预警、存休管理 |
| 薪酬核算 | 月度薪酬自动核算、明细查看 |
| 员工管理 | 员工档案、花名册、工资单查看 |
| 规则引擎 | 规则自定义（新增/编辑/删除/启用停用），公式计算自动生效 |

## 技术栈

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **后端**：Node.js + Express + SQLite
- **规则引擎**：基于数据库的规则表，支持动态加载

## 快速开始

```bash
# 安装依赖
npm install

# 终端 1——启动后端 API（端口 3001）
node server/index.js

# 终端 2——启动前端（端口 5173）
npx vite --port 5173 --host
```

打开浏览器访问 `http://localhost:5173`。

> **局域网共享**：将 `src/App.tsx` 中的 `const API` 改为相对路径 `/api`，并通过 Vite 代理转发后端请求，同事即可通过 `http://<你的IP>:5173` 访问。
