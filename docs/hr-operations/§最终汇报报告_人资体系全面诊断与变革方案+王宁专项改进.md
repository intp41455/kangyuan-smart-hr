## 第一章 规则体系全景：具体规则内容与底层逻辑

### 1.1 组织架构与核算主体

康源集团通过**4大核算主体**运营养老与教育业务，下设**15家以上实体公司**和**25家分支机构和项目公司**：

| 核算主体 | 覆盖范围 | 工资独立核算 | 社保独立缴纳 |
|----------|----------|-------------|-------------|
| 康源福祉教育 | 西安本部教育业务、蓝田家政学校 | ✅ | ✅（部分人员上海代缴） |
| 上海康源博曜 | 上海地区业务 | ✅ | ✅（由中成代缴部分） |
| 康源美宏养老 | 西安美宏系各机构 | ✅ | ✅ |
| 康源中成养老 | 中成系各机构 | ✅ | ✅ |

**关键影响**：每家实体公司需独立签订劳动合同、独立缴纳社保公积金、独立编制工资表。集团308+员工分布在4套工资表、4套社保系统中，这是人工核算工作量巨大的**结构性根源**。

### 1.2 七大类HR管理制度体系

#### 1.2.1 招聘录用管理

**核心原则**（5项）：公开、公平、公正、择优录用 + 内部竞聘优先

**不予二次入职的6种情形**：
1. 严重违反公司规章制度被解除劳动合同
2. 未办妥离职手续擅自离职
3. 在岗期间有贪污挪用行为
4. 泄露公司商业秘密
5. 入职体检不合格或弄虚作假
6. 其他不适合再次录用的情形

**亲属回避3级范围**：直系亲属（父母/配偶/子女）→ 三代以内旁系血亲 → 近姻亲关系

**11种不符合录用条件**：包括提供虚假材料、隐瞒重大疾病、隐瞒劳动关系/竞业限制、有违法犯罪记录、体检不合格、试用期考核不合格、5天内自离不结算工资等。

#### 1.2.2 入职管理

**背景调查**：关键岗位（财务、管理、技术）须进行背景调查。

**9项必交资料**（7个工作日内提交）：身份证/学历证/学位证/职称证/离职证明/体检报告/银行账户/社保转移单/一寸照片。

**5种合同类型**：
| 合同类型 | 适用对象 | 期限 |
|----------|----------|------|
| 劳动合同 | 正式员工 | 1年/3年/无固定期限 |
| 劳务服务协议 | 劳务用工 | 按项目约定 |
| 实习协议 | 实习生 | 按学校安排 |
| 退休返聘协议 | 退休返聘人员 | 1年一签 |
| 保密及竞业限制协议 | 全员 | 离职后2年 |

**15家实体公司差异化合同模板**：集团、福祉、博曜、中成、安德福、壹心、小葵、康隆、成都、美宏、耆祥、荣德康、荣德康福、逸晖等各有一套劳动合同/劳务协议/实习协议/保密协议。

**信息变更1周内报备**：员工住址、联系方式、紧急联系人等变更须在1周内通知人资。

#### 1.2.3 试用期与晋升代理期管理

**试用期薪资**：岗位标准薪资 × 80%

**试用期期限与合同期限挂钩**：
| 合同期限 | 试用期 | 依据 |
|----------|--------|------|
| 1年 | 1个月 | 《劳动合同法》第19条 |
| 3年/无固定期限 | 3个月 | 《劳动合同法》第19条 |

**晋升代理期**：6-12个月，代理期内薪资按新岗位标准发放，期满考核合格正式任命。

**7种不符合转正条件**：试用期考核不合格/严重违纪/提供虚假材料/隐瞒重大疾病/5个工作日内自离不结算工资/不符合岗位任职资格/其他不适合留用情形。

#### 1.2.4 调动管理

**3种调动类型**：晋职（升职）、降职、平调

**3个月观察期**：调动后设3个月观察期，观察期考核不合格可退回原岗位。

**假期跨公司处理规则**：
- **调休假不跨公司**：调动后原公司调休假不可带入新公司
- **年假可顺延**：调动后年假可顺延至新公司继续使用
- **调动日期规则**：1-15日调动算新公司当月出勤，16日以后算原公司

#### 1.2.5 离职管理

**4种离职类型**：主动辞职、协商解除、公司辞退、合同到期不续签

**预告期**：试用期提前3日、正式员工提前30日书面通知

**4方交接确认**：工作交接（主管确认）+ 行政交接（行政确认）+ 财务交接（财务确认）+ 人事交接（人资确认）

**经济补偿**：
- 培训违约金：公司出资培训后约定期限内离职需按比例返还培训费
- 竞业限制补偿：离职后按月发放竞业限制补偿金（不超过离职前12个月平均工资的30%）

#### 1.2.6 考勤及休假管理（核心制度）

**（一）作息时间**

| 岗位类型 | 冬令时(11月-4月) | 夏令时(5月-10月) | 休息制度 |
|----------|------------------|------------------|----------|
| 行政/职能岗 | 08:30-17:30 | 08:30-17:30 | 单休（周日休息） |
| 护理岗A班 | 07:00-15:00 | 07:00-15:00 | 三班倒轮休 |
| 护理岗P班 | 15:00-23:00 | 15:00-23:00 | 三班倒轮休 |
| 护理岗N班 | 23:00-07:00 | 23:00-07:00 | 三班倒轮休 |

**（二）打卡规则**

- **工具**：钉钉人脸识别打卡
- **要求**：上下班各打1次，须在工作地点范围内
- **出差打卡**：出差期间仍须上下班打卡（王宁聊天记录2025-09-03明确："出差也要上下班打卡，没打就是不符合全勤"）

**（三）全勤奖**

| 条件 | 标准 |
|------|------|
| 整月出勤 + 补卡≤3次 + 无请假 + 无迟到早退 + 无旷工 | 100元/月 |
| 新入职或离职当月 | 0元（例外：达到实际应出勤天数则发） |
| 任何一项不满足 | 0元 |

**（四）补卡规则**

- 每月最多3次免费补卡
- 超过3次：全勤奖清零 + 每超1次扣10元
- 补卡须钉钉申请 + 主管审批

**（五）迟到/早退4级梯度处罚**

| 级别 | 条件 | 处罚 |
|------|------|------|
| 1级 | 迟到/早退 ≤30分钟 | 10元/次，全勤奖清零 |
| 2级 | 迟到/早退 >30分钟 | 按事假半天处理 |
| 3级 | 迟到/早退 >60分钟 | 按旷工1天计算 |
| 升级 | 月累计≥3次 | 扣绩效 + 通报批评 |
| 严重 | 月累计>5次 | 可降职/降级/解除劳动合同 |

**（六）旷工**

| 天数 | 后果 |
|------|------|
| 1天 | 通报批评 + 扣绩效 |
| 2天及以上 | 严重违纪，可解除劳动合同 |

**（七）病假3级梯度（2024版）**

| 病假天数 | 日薪比例 | 计算公式 |
|----------|----------|----------|
| ≤7天 | 80% | 日薪 × 80% × 病假天数 |
| 8-15天 | 50% | 日薪 × 50% × 病假天数 |
| >15天 | 最低工资80% | 当地最低工资 × 80% × 病假天数 |

> **日薪计算**：岗位标准薪资 ÷ 21.75天

> **制度对比**：2022版病假≤7日仅50%，2024版提升至80%；2024版新增8-15日中间档50%，形成3级梯度。

**（八）事假**

事假期间工资全额扣除：日薪 × 事假天数

**（九）年假**

| 工龄 | 年假天数 | 有效期规则 |
|------|----------|-----------|
| 1-10年 | 5天 | 入职时间在上半年(1.1-6.30)的，当年即可享受，有效期至次年12月31日 |
| 10-20年 | 10天 | 入职时间在下半年(7.1-12.31)的，满1年后开始享受，有效期至次年6月30日 |
| 20年以上 | 15天 | 同上 |

**年假特殊规则**：
- 年假可抵扣病假/事假
- 年假可预支（如田冬梅2026年1月4日休年假，实际年假从6月19日入职周年日起算 — 预支需领导审批同意）
- 延期申请须在当年12月31日前提交，经审批后最多延长至次年6月30日
- 逾期未申请延期的年假系统自动清零

**（十）其他假期**

| 假期类型 | 天数 | 备注 |
|----------|------|------|
| 婚假 | 3天 | 晚婚(男25/女23周岁)额外增加 |
| 产假 | 158天 | 含法定98天+陕西省60天奖励假 |
| 陪产假 | 15天 | 陕西省标准 |
| 丧假 | 3天 | 直系亲属(父母/配偶/子女) |
| 调休假 | 按加班时长 | 当年12月31日前休完，逾期清零 |

**（十一）加班规则**

**加班有效三要素**（缺一不可）：
1. 钉钉提交加班申请
2. 主管审批通过
3. 上下班打卡记录

**加班费计算**：
| 加班类型 | 倍率 | 计算公式 |
|----------|------|----------|
| 工作日加班 | 1.5倍 | 时薪 × 1.5 × 加班小时 |
| 休息日加班 | 2倍 | 日薪 ÷ 8 × 2 × 加班小时 |
| 法定节假日加班 | 3倍 | 日薪 ÷ 8 × 3 × 加班小时 |

> **调休优先**：休息日加班优先安排调休，无法调休的按2倍支付加班费。

**（十二）存休（调休）结转规则**

- 当年加班产生的调休假须在当年12月31日前休完
- 经审批可延长至次年2月28日（如福祉教育2025年调休延期至2026年2月28日）
- 逾期未休完的调休假清零
- 调休假不跨公司（调动后原公司调休假不可使用）

### 1.3 薪酬核算体系

#### 1.3.1 工资结构（11步计算公式链）

```
第1步：岗位标准薪资（合同约定）
  ↓
第2步：固定工资 = 岗位标准 × 90%
  ↓
第3步：绩效工资 = 岗位标准 × 10% × 绩效系数
  ↓
第4步：全勤奖 = 100元（满足条件）/ 0元（不满足）
  ↓
第5步：工龄工资 = 满1年100元/满2年200元/满3年300元/满5年500元/满10年800元
  ↓
第6步：各项补贴 = 交通补贴 + 课时费 + 评估费 + 其他津贴
  ↓
第7步：应发工资 = 固定工资 + 绩效工资 + 全勤奖 + 工龄工资 + 各项补贴
  ↓
第8步：病假扣款 = 日薪 × (1-病假比例) × 病假天数（3级梯度）
  ↓ 事假扣款 = 日薪 × 事假天数
  ↓ 迟到扣款 = 10元 × 次数（或按事假/旷工处理）
  ↓
第9步：社保公积金扣款 = 养老8% + 医疗2% + 失业0.3% + 公积金5%
  ↓
第10步：个税 = 累计预扣法 × 7级超额累进税率 - 速算扣除数
  ↓
第11步：实发工资 = 应发工资 - 病/事假扣款 - 迟到扣款 - 社保公积金 - 个税
```

#### 1.3.2 绩效计算公式

```
当月绩效工资 = 绩效工资标准 × (1 + 3 × (季度绩效分数 - 100) / 100)
```

| 绩效分数 | 绩效系数 | 说明 |
|----------|----------|------|
| 100 | 1.0 | 基准 |
| 115 | 1.45 | 加45% |
| 150.53 | 2.5159 | 加151.59% |

- "3"的含义：季度3个月的绩效调整在当月一次性发放/扣除
- 绩效考核比例：个人薪酬总额的10%（固定工资90% + 绩效工资10%）
- 上海博曜仅高强每季度进行绩效应用

#### 1.3.4 月计薪天数

**标准公式**：(365天 - 104天周末) ÷ 12个月 = **21.75天/月**

**实际月计薪天数**：根据当月实际工作日 + 法定节假日计算（王宁聊天记录中多次纠正康小源的计算）：
- 2025年2月：19天（王宁2025-03-05纠正）
- 2025年6月：22天 = 上班19天 + 法定3天（王宁2025-06-04纠正）
- 2025年7月：20天（王宁2025-07-03纠正）
- 2025年8月：23天（王宁2025-08-04纠正）

### 1.5 审批层级体系

**统一审批链**：
```
主管领导/院长 → 分管领导 → 人力资源总监 → 总裁 → 董事长
```

**按公司类型差异化**：
| 公司类型 | 审批层级 | 适用机构 |
|----------|----------|----------|
| 自营 | 主管→分管→HR→总裁→董事长 | 美宏/中成/逸晖等 |
| 合资 | 主管→合资方代表→HR→总裁→董事长 | 壹心/安德福等 |
| 委托运营 | 主管→委托运营方→HR→总裁→董事长 | 部分项目 |

**请假审批分层**：
| 请假天数 | 审批层级 |
|----------|----------|
| <5天 | 主管→分管 |
| 5-10天 | 主管→分管→HR总监 |
| ≥10天 | 主管→分管→HR总监→总裁 |

### 1.6 4套社保系统独立操作体系

### 4.2 规则引擎可编码条款清单

以下制度条款已从原文验证，可直接转化为规则引擎代码：

```python
# === 考勤规则引擎核心逻辑 ===

# 1. 全勤奖判定
if 出勤整月 and 补卡次数 <= 3 and 无请假 and 无迟到早退 and 无旷工:
    全勤奖 = 100
elif 新入职或离职当月:
    if 实际出勤天数 == 应出勤天数:
        全勤奖 = 100
    else:
        全勤奖 = 0
else:
    全勤奖 = 0

# 2. 补卡规则
if 补卡次数 <= 3:
    补卡有效 = True
else:
    全勤奖 = 0
    超次扣款 = (补卡次数 - 3) * 10

# 3. 迟到/早退4级梯度
if 迟到或早退:
    全勤奖 = 0
    if 迟到时长 <= 30:
        扣款 = 10 * 次数
    elif 迟到时长 <= 60:
        按事假半天处理
    else:
        按旷工1天处理
    if 月累计 >= 3:
        扣绩效 + 通报批评
    if 月累计 > 5:
        可降职/降级/解除合同

# 4. 病假3级梯度（2024版）
if 病假天数 <= 7:
    病假工资 = 日薪 * 0.8 * 病假天数
elif 病假天数 <= 15:
    病假工资 = 日薪 * 0.5 * 病假天数
else:
    病假工资 = 当地最低工资 * 0.8 * 病假天数

# 5. 试用期薪资
if 试用期:
    薪资 = 岗位标准薪资 * 0.8

# 6. 工龄工资（含调动规则）
if 司龄 >= 1: 工龄工资 = 100
if 司龄 >= 2: 工龄工资 = 200
if 司龄 >= 3: 工龄工资 = 300
if 司龄 >= 5: 工龄工资 = 500
if 司龄 >= 10: 工龄工资 = 800
# 调动规则：1-15日调动算新公司，16日以后算原公司

# 7. 绩效计算
当月绩效工资 = 绩效工资标准 * (1 + 3 * (季度绩效分数 - 100) / 100)

# 8. 日薪计算
日薪 = 岗位标准薪资 / 21.75

# 9. 加班费
工作日加班费 = 时薪 * 1.5 * 加班小时
休息日加班费 = 日薪 / 8 * 2 * 加班小时
法定节假日加班费 = 日薪 / 8 * 3 * 加班小时

# 10. 橄榄枝协议违约金
if 未完成合同期:
    违约金 = 已发放留用奖励全额返还
```

- 推动钉钉审批抄送规则配置，确保相关人自动收到

#### 问题5：社保跨公司代缴依赖人工记忆和手动转账

**证据**（2026-06-02、2026-06-04聊天记录）：
- 高强社保由中成代缴，每月需手动发起转账申请1,850.48元

**影响**：
- 跨公司社保代缴涉及多笔转账，易遗漏
- 王宁对转账账户信息不熟悉（"你和李婧婧问一下"）
- 社保缴费明细需找李婧婧索取（"每月都要找李婧婧要"）

**改进建议**：
- 王宁应建立《跨公司社保代缴台账》，记录所有代缴关系、转账方向、金额、账户
- 推动社保代缴转账自动化（定期付款申请自动生成）
- 与李婧婧建立定期数据同步机制

#### 问题6：个税核定流程被动等待，缺乏预判能力

**证据**：
- 王宁每次工资表编制完成后，都要等财务核定个税，然后发回"个税终"版本
- 2026-06-04王宁对康小源："个税都先删掉，等财务核定这个月的"
- 2026-06-10王宁发回核定版："核定过个税版，请查收，并以此用于工资条发放"

**影响**：
- 个税核定成为工资发放的关键路径，财务延迟则全链路延迟
- 王宁对个税计算（累计预扣法、7级超额累进）缺乏自主核算能力
- 无法在工资表初稿阶段提供含个税的完整预览

**改进建议**：
- 王宁应学习并掌握个税累计预扣法计算逻辑
- 在工资表初稿阶段自行计算个税预估，财务仅做最终核定
- 推动个税计算引擎部署，减少对财务的依赖

#### 问题7：考勤版本控制意识缺失

**证据**：微信文件目录扫描发现考勤汇总表70+版本在王宁与各机构行政之间传输：
- 文件名包含"已确认""最终版""最终版本2.0""已确定版本"等矛盾命名
- "最终"之后还有"最终"，"已确认"之后还在修改
- 2024-10甚至出现"8月考勤(10.8改动)"——次月仍在改上月

**影响**：
- 版本混乱导致无法确认哪个是最终版
- 修改痕迹无法追踪，出错后无法定位责任人
- 归档时不知道应存哪个版本

**改进建议**：
- 王宁应推动考勤汇总表版本控制制度：
  - 文件命名规范：`{公司}{年月}考勤汇总_v{版本号}_{日期}_{制作人}.xlsx`
  - 每次修改须在文件内"修改记录"Sheet中记录修改内容/修改人/修改时间
  - 最终确认版加锁，不允许再修改
- 推动钉钉文档在线协作，自动保留版本历史

#### 问题8：被动执行多于主动优化，缺乏改进提案能力
