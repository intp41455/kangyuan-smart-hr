## 1. 解密过程

### 1.1 技术方案

微信4.1+采用SQLCipher 4加密（AES-256-CBC + HMAC-SHA512），不再在进程内存中缓存raw key，传统内存扫描方法完全失效。本次使用TANGandXUE/wcdb-key-tool的**运行时Config.Cipher只读扫描**方案：

1. 在微信进程中定位`com.Tencent.WCDB.Config.Cipher`对象
2. 解码出候选`x'<key><salt>'`片段
3. 用数据库HMAC验证候选密钥
4. 扫描PID=40676进程，找到27个候选，23/23个salt全部匹配

### 1.2 解密结果

### 2.2 "周五催收循环"模式（核心发现）

**这是HR运营中最大的效率痛点。** 王宁每周五上午（通常8:45-9:11之间）发送完全相同模板的消息：

> 各位行政好[太阳]，周五了，请大家在12点之前将如下资料发我，如截止12点未发的，将在群内@未提交人员[衰]
> 【最新花名册】如花名册无变动，请单独发信息说明
> 【入转调离签字版扫描件】
> 【意外险参保名单或保单】
> @一只小fei杨🧚🏻 @西城—王春妮 @LI @财鑫➕行政➕于莎➕15628696896 @护理院曹建雅 @晴天🌻 @逸晖 行政 宗红玲 @南蔷 @歡.

**统计**：在2026年2月至6月的群聊记录中，此模板消息出现了至少**12次**（几乎每周五一次）。

- "截止目前仍未收到西城、壹心、逸晖、财鑫和陵城、耆祥的内容，请及时发送[抱拳]"

### 4.2 AI自动化改造方案

**目标**：将"周五催收循环"从3-5个工作日压缩至4小时自动完成。

**架构**：
```
钉钉考勤/审批 → 自动采集 → AI解析校验 → 规则引擎计算 → 智能提醒 → HR确认
     ↓              ↓           ↓            ↓           ↓
  原始数据      结构化数据   异常标记     工资预计算   逾期升级
```

**关键改造**：

1. **统一数据收集看板**（替代微信催收）
   - 各机构行政登录钉钉看板查看待提交项
   - 系统自动检测花名册变更，无变更则自动标记"无变动"
   - 提交状态实时可视化（已提交/待提交/逾期）

2. **智能提醒Agent**（替代手动@和追催）
   - 周四自动推送提醒（非周五，给1天提前量）
   - 周五12:00自动向未提交者发送钉钉DING消息
   - 周五15:00自动向机构负责人升级提醒
   - 周一自动汇总上周提交情况报告

3. **考勤自动汇总**（替代手工考勤表收集）
   - 钉钉打卡数据自动导出为考勤汇总表格式
   - AI自动标记异常（缺卡/补卡/加班/请假）
   - 各机构行政只需确认异常项，无需手工录入

4. **文件统一管理**（替代微信群文件分发）
   - 所有制度文件上传至钉钉文档/知识库
   - 新文件自动推送通知+阅读确认
   - 版本控制+权限管理
